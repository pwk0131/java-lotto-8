## **기능 구현 목록**

### 1️⃣ 입출력
- [ ] 로또 구입 금액 입력 받기
- [ ] 당첨 번호 (6개) 입력 받기 (쉼표로 구분)
- [ ] 보너스 번호 (1개) 입력 받기
- [ ] 구입한 로또 개수 출력
- [ ] 구입한 로또 번호 (오름차순 정렬) 목록 출력
- [ ] 당첨 통계 (일치 개수, 당첨금, 개수) 출력
- [ ] 총 수익률 (소수점 둘째 자리에서 반올림) 출력
- [ ] 예외 발생 시 "[ERROR]"로 시작하는 메시지 출력

### 2️⃣ 핵심 로직
- [ ] 구입 금액에 맞춰 로또 자동 발급 (1,000원당 1개)
- [ ] 1~45 범위의 중복되지 않는 6개 숫자로 로또 생성 (Randoms.pickUniqueNumbersInRange)
- [ ] 구매한 로또와 당첨 번호 비교
- [ ] 로또별 당첨 등수(Rank) 판별
- [ ] 당첨 등수(Enum) 관리 (1등~5등, 꽝)
- [ ] 등수별 당첨금 및 일치 조건 정의 (Enum 활용)
- [ ] 2등(5개 일치 + 보너스) 판별 로직 구현
- [ ] 전체 당첨 내역 집계 (Map<Rank, Integer>)
- [ ] 총 투자 대비 총 수익률 계산

### 3️⃣ 예외 처리 및 유효성 검사
- [ ] 구입 금액이 1,000원 단위가 아닐 경우 예외
- [ ] 구입 금액이 1,000원 미만일 경우 예외
- [ ] 구입 금액이 숫자가 아닐 경우 예외
- [ ] Lotto.java 클래스: 6개가 아닐 경우 예외
- [ ] Lotto.java 클래스: 번호가 1~45 범위 밖일 경우 예외
- [ ] Lotto.java 클래스: 번호에 중복이 있을 경우 예외
- [ ] 당첨 번호가 6개가 아닐 경우 예외
- [ ] 당첨 번호가 1~45 범위 밖일 경우 예외 (Lotto 클래스 위임)
- [ ] 당첨 번호에 중복이 있을 경우 예외
- [ ] 당첨 번호가 숫자가 아닐 경우 예외
- [ ] 보너스 번호가 1~45 범위 밖일 경우 예외 (LottoNumber 클래스 위임)
- [ ] 보너스 번호가 숫자가 아닐 경우 예외
- [ ] 보너스 번호가 당첨 번호와 중복될 경우 예외
- [ ] 예외 발생 시 해당 부분부터 입력 다시 받기

## **클린코드 확인 사항**
- [ ] 자바 코드 컨벤션 준수
- [ ] indent(들여쓰기) 1단계 유지 (메서드 분리)
- [ ] else 예약어 쓰지 않기 (if-return, Enum, Predicate 활용)
- [ ] 모든 원시값과 문자열 포장 (e.g., PurchaseAmount, LottoNumber)
- [ ] 콜렉션에 대해 일급 콜렉션 적용 (e.g., Lottos, Statistics)
- [ ] 3개 이하의 인스턴스 변수 사용 (모든 클래스 준수)
- [ ] getter/setter 금지 (도메인 로직은 Tell, Don't Ask, View는 DTO/getter 최소화)
- [ ] 메소드 인자 수 제한 (4개 미만)
- [ ] 코드 한 줄에 점(.) 하나만 허용 (도메인 객체 내부 제외)
- [ ] 메소드가 한가지 일만 담당
- [ ] 클래스를 작게 유지
